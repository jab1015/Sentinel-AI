Status: Active

# Purpose

Define the production verification requirements for Sentinel AI across supported Windows versions.

# Supported Platforms

- Windows 11
- Windows 10

# Verification Requirements

The application must:

- Launch successfully.
- Display personalized user experience.
- Complete monitoring initialization.
- Display system evidence correctly.
- Preserve Ask Sentinel safety boundaries.
- Avoid crashes during normal operation.
- Maintain Windows security integration behavior.

# Evidence Requirements

Compatibility verification requires runtime evidence from supported Windows environments. Repository implementation alone does not constitute completion.
